## 🧠 How I work with AI

- **Spec first, then build** – I write the rules of the workflow (what counts as a delay, which lot wins when an address is ambiguous) before any code, so the AI builds the right thing.
- **Test what ships** – headless tests (Streamlit AppTest, Playwright) run the real flows; demos are verified live, not just locally.
- **Ship for non-technical users** – one-click web demos, bilingual UI, fictional sample data, no API keys in repos.
